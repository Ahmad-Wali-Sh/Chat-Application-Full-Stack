# Chat Application Overview

This application created via React, Express and Its plugins and PostgreSQL, mainly for entertainment and learning concepts.

Chat Application Provides an interface which we can interreact with it, add new messages, see other messages and also send locally videos, images and so on with nice frontend and strong backend.

Here is some features provided:

- [ ]  Account Based Solution for Authentication and Authorization
- [ ]  Rooms For Different People With Contact
- [ ]  Rooms Types (Group, Channel and Personal P2P)
- [ ]  Messaging Capabilities and Video Audio and Image Sharing
- [ ]  Settings
    - [ ]  Changing Name, username and password and profile picture
    - [ ]  Changing Theme of Actual Chat Application
- [ ]  Responsive Design For Both Laptops and Mobiles.
- [ ]  Dari/Pashto and English
